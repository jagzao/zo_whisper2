# FEATURE-ZMI-003 — Community and Public CI Readiness

## Outcome

An external contributor can understand how to report issues, propose changes, run checks locally, and see lightweight automated PR validation.

## Scope

- Restore lightweight GitHub PR workflows for quality/security/unit/smoke/E2E.
- Keep heavy/long-running soak work in Jenkins.
- Gitleaks secret scanning.
- Issue templates + PR template + Code of Conduct.
- Reconcile README, SECURITY, CONTRIBUTING and LOCAL-OPS with actual tooling.
- Community-launch checklist for rename/metadata/topics/Discussions/tag/release after owner acceptance.
