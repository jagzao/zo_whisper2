User guide

Basic flow

  1. Upload files with the Drop Area. They go to Video_compress/. Optionally choose a project to auto-rename with prefix.
  2. Press RUN Full to compress, organize by project and transcribe.
  3. In Files → Transcriptions you will see the status, detected language and whether it already has a transcription.
  4. Use View to play the audio/video alongside its transcription, or Edit to correct the text.

Language prefixes

  • es_ forces Spanish.
  • en_ forces English.
  • No prefix: uses project language or auto-detection.

Project prefixes

Defined per project in projects.json (see projects.json.example). Example:

  • zo_ → Zo Interviews
  • northwind_ → Northwind
  • contoso_ → Contoso Team
  • fabrikam_ → Fabrikam
  • meeting_, junta_ → Dev Meetings
  • tutorial in the name → Tutorials

Projects

The grid icon opens the project CRUD. There you can create/edit/delete projects, prefixes, language and Whisper initial prompt.

Logs

The document icon opens real-time logs to debug errors.
