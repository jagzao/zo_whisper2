Set up secure Whisper access

Install Whisper's public certificate on this phone, then open the secure site.

Install Whisper certificate

Samsung / Android

  1. Go to Settings > Security and privacy > More security settings > Credential storage > Install from device storage > CA certificate.
  2. Authenticate, select Whisper-LAN-Local-CA.cer, then confirm installing it as a CA certificate.
  3. Confirm Android's security prompt. Menu wording varies by version.

Android requires your confirmation. Whisper does not install certificates silently.
